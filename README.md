# Share_Trip
Данный проект - это сервис поиска попутчиков для совместных поездок.

## Приложение позволяет:
    - Создавать поездки;
    - Получать информацию о поездке;

## Tools:
    Go
    pgx
    docker
    fiber

## Структура проекта:

## Запуск

1. Запустить Docker:
- make up

2. Применить миграции:
- make migrate-up

3. Запустить приложение:
- make run 

## API:
/trip/create       - создать поезду
/trip/:id          - посмотреть информацию о поездке
/trip/publish      - опубликовать поездку
